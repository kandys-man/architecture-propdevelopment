## Роли, их полномочия и группы пользователей

**Проблемы бизнеса, объясняющие создание сущностей partner, client**

1. Партнёр(partner) из одной управляющей компании может увидеть или изменить данные клиентов и жилищных комплексов, которые относятся к другой компании.
2. Личный кабинет клиента(client). Там иногда могут отображаться данные другого клиента.

|  Роль   |                    Права роли                  |Группы пользователей|
|---------|------------------------------------------------|--------------------|
| admin   |Может настраивать кластер                       |Бизнес-аналитик     |
| client  |Есть право только на просмотр ресурсов кластера |Менеджер, client    |
| partner |Просмотр секретов                               |Аналитик BI, partner|
